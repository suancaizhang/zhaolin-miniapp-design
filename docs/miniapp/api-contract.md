# 本地作品馆接口与运行边界

状态：0.1.0-local本地工程接口，线上部署未批准；真实微信编译/真机验证以测试报告为准。用户的AppID只保存在本机私有配置，不写入本文。

## 运行与数据

- 本地服务默认`http://127.0.0.1:8788`，仅监听回环地址；不能直接供手机、异地维护者或分享接收者访问。
- 小程序读取公开内容；电脑后台使用本地维护者登录。两位维护者权限相同、直接维护，不增加审批、草稿版本或撤下工作流。
- SQLite及原图/展示图位于忽略目录`data/`。原图不直接公开；上传检查真实图像内容，生成缩略图与欣赏图，不裁切作品主体。
- 新库的作品、系列和图片为空。`server/source-index.json`包含43条既有笔记标识、发布时间和整理分类，仅初始化为待作者确认的来源，不自动归并作品或导入原型截图。
- 作品ID由服务端生成并保持稳定；标题、系列归属、封面或顺序修改不更换ID。系列只保存关联关系，不复制作品。
- 记录的阶段为线稿/设色/完成效果；视角为整体/局部，分别保存。可靠日期可空，不用笔记发布时间代替创作日期。材料、尺寸与年份有真实资料才填。

## 传输与错误

成功响应为`{data: ...}`，退出登录成功为204无正文。错误为`{error:{code,message,fields?}}`；fields为表单字段错误，不回显密码、会话或内部堆栈。

| HTTP | 语义 |
| --- | --- |
| 400 | 无效JSON或请求格式 |
| 401 | 未登录或会话失效 |
| 403 | 不允许的来源或CSRF校验未通过 |
| 404 | 路由或内容不存在 |
| 413 | JSON正文或上传体积超限 |
| 422 | 内容字段不满足约束 |
| 429 | 登录尝试受限 |
| 500 | 服务暂不可用，客户端不获得内部错误 |

写入不自动重试；用户看到错误后保留输入，可核对后重新提交。新建请求没有幂等键约定，不能盲目自动重发。

## 接口

| 方法与路径 | 用途与权限 |
| --- | --- |
| GET `/api/health` | 本地服务就绪检查 |
| GET `/api/catalog` | 当前作品馆公开内容快照：works、series；用于规模较小的单作者目录 |
| GET `/api/works/:id` | 按稳定ID独立读取作品；分享冷启动不能依赖发送者缓存 |
| GET `/api/series/:id` | 系列资料及引用的作品 |
| GET `/api/session` | 当前维护者与CSRF令牌；未登录时为null |
| POST `/api/session` | JSON账号密码登录；不提供默认账号 |
| DELETE `/api/session` | 校验会话及CSRF后退出，不是注销账号 |
| GET `/api/admin/catalog` | 登录后读取可维护的作品、系列、图片及43条来源 |
| POST `/api/admin/images` | 登录并校验CSRF后上传原始图像字节；不是multipart |
| PUT `/api/admin/images/:id` | 维护图像说明与整体/局部视角 |
| POST `/api/admin/works` | 新建完整作品 |
| PUT `/api/admin/works/:id` | 修改完整作品表示；保留同一ID |
| POST `/api/admin/series` | 新建系列 |
| PUT `/api/admin/series/:id` | 修改系列名称、说明、封面与顺序；不改变已有作品ID |
| PUT `/api/admin/sources/:id` | 关联作品/记录，或保留明确的待确认原因 |

所有`/api/admin`接口需维护者会话；管理写入与退出登录还需`X-CSRF-Token`。图片上传的Content-Type仅JPEG/PNG/WebP，`X-File-Name`使用encodeURIComponent编码；限制12MiB、40MP，服务器重新解码验证，生成最长边480px缩略图和2400px欣赏图，不放大小图。

完整字段类型以`shared/types.ts`为准。作品写入使用imageIds，读取时展开为images；图像地址为`/media/:id/...`相对路径，客户端按实际服务地址解析。服务器验证图片与系列是否存在、整体展示图视角、必填字段、阶段/视角、可靠日期及来源引用；无效提交不得污染已保存内容。

来源归属是单一事实：关联到作品的来源在该作品维护页中呈现；记录必须属于选定作品。改变已有归属时使用来源管理入口，不靠重复录入冒充归并。没有确定归属的来源保留原因。

作品页取消已关联来源时，服务自动将它恢复待确认并填入统一原因“待作者确认作品归属与正式素材”；在来源页直接取消归属则必须填写待确认原因。来源仍引用的记录不能直接从作品输入中移除；先调整来源关联。

## 本地安全边界

- 密码以随机盐scrypt保存，不保留明文，不通过源码、URL或日志传递。维护者仅通过本机交互命令创建；同名账号不自动重置。
- 会话凭证为HttpOnly、SameSite=Strict Cookie，服务端保存摘要并设置过期时间；浏览器不将登录凭证存入localStorage。CSRF令牌只在当前页面内存使用，不代替会话鉴权。
- HTTP只用于本机回环联调，因此本地Cookie不设置Secure；这不是公网部署配置。公开托管前必须单独设计HTTPS、域名、Cookie、访问来源及账户备份策略。
- 默认仅接受本地后台和本地Vite界面的来源；不使用任意来源CORS，不开放项目根目录、私有配置、数据库或原图目录。
- 没有支付、删除/清空、注销、撤下或外部通知接口；不为未批准业务增加危险操作。

## 生命周期与未验证项

目录在进入/返回时向后台刷新，不将多个系列维护成互不一致的副本。详情以路径ID重新读取；重新打开不恢复上一维护者密码或本机私有数据。电脑表单保存失败保留当前输入；登录失效提供重新登录路径。

真实微信朋友分享只能在接收者能访问同一公网服务时验证；本地127.0.0.1不满足该条件。开发者工具本地关闭域名校验仅可用于联调，不是上线配置。备案、类目适配、隐私资料、原图与作品归并等未完成项不会因接口运行而自动完成。
