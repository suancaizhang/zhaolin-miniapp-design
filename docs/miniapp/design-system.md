# 召麐个人作品馆 · B方向设计规范

状态：**B方向与完整设计已获用户确认，当前进入环境准备**。确认日期：2026-10-22。本文是高保真设计与实现映射，不是已运行的小程序、线上后台或已批准的技术架构；设计确认不补记任何运行证据。

## 1. 目的、范围与批准边界

- 目标：让普通观众及绘画爱好者先欣赏作品整体，再看局部与创作过程，最后可向微信朋友转发作品入口。暖白、柔和卡片、克制朱红辅助作品，不抢夺画面注意力。
- 已确认：产品需求、首版范围、B「TDesign品牌定制」方向及完整设计；唯一主组件体系为 **TDesign MiniProgram**，原生两项 tabBar 配本地 PNG。设计确认不等于运行、上线或费用确认。
- 本轮交付：连通手机页面与电脑核心编辑页的 HTML 设计原型。入口为 [prototype/index.html](prototype/index.html)，不是最终 WXML/WXSS 工程。
- 首版包括：精选、系列、全部作品、详情、图片放大、微信作品入口分享；两位同权维护者的电脑后台及共享内容能力。此轮只演示这些界面，不实际登录、上传、发布或持久化。
- 不增加：收藏、下载按钮、联系作者、评论、交易、教程、朋友圈分享、自动抓取；不设计草稿、作者审批、版本冲突、撤下恢复或旧分享专项工作流。
- 需求语义以 [产品决策](../../PRODUCT-DECISIONS.md)、[词汇表](../../GLOSSARY.md) 为准；范围见 [项目规划](project-plan.md)，B方向确认见 [决策记录](decisions.md)。技术方案、账号方式、数据存储与部署仍待确认；不因本设计采用 React、TDesign React 或任何后台框架。

原生布局用WXSS的`view/text`、flex、padding、margin、border、background-color实现。375基准下布局尺寸可按1px≈2rpx换算，但44px热区不能随窄屏缩小；字体需结合系统放大策略适配，不以rpx缩放代替大字体支持。TDesign优先使用公开CSS变量与外部样式类，不穿透修改库内部结构。不能依赖渐变、毛玻璃、混合模式、CSS遮罩、视差、3D、复杂动画或Web专用布局产生核心效果；无阴影也应保持清楚层级。

### 核心效果映射表

下列映射为设计实现说明，尚未编译；公开API已读到的依据见第11节。原型中的HTML元素不能原样移入小程序。

| 核心效果 | WXML / 平台映射 | WXSS / 交互与降级 |
| --- | --- | --- |
| 全页和章节层级 | `view`、`text`、页面滚动；有明确独立滚动需求才用`scroll-view` | flex换行、间距与纯色；双列不足则单列，不使用瀑布流或复杂Grid依赖 |
| 顶部与返回 | 原生`window.navigationBar*`、页面导航与返回能力 | 暖白底、黑色导航字；保留微信胶囊原状，不能以Web覆盖层侵入系统区域 |
| 两项底部导航 | 原生`app.json.tabBar.list`，两组本地PNG | `color=#6e685f`、`selectedColor=#8f332b`、`backgroundColor=#faf8f3`；原生边框仅支持black/white，不承诺精确自定义边框色或52px高度 |
| 作品/系列卡片 | `view`包裹`image`与`text`，导航点击映射到同一稳定作品ID | 背景、12px圆角、边框与flex；卡片无悬停必要效果。边界装饰失败也不影响阅读与点击 |
| 整体图、封面、记录图 | 原生`image mode="aspectFit"`，显式宽高；自然高度场景可用`widthFix` | 原图完整保留比例，留白优于裁掉画面；不默认`aspectFill`。`bind:error`呈现该图片错误与重试，不替换成无关作品 |
| 图片放大 | `wx.previewImage({current, urls})`，当前图与同作品图列表 | HTML弹层仅模拟欣赏入口；正式由原生预览接管。失败保留详情并显示重试；不得冒充已成功打开 |
| 主要/次要/文字按钮 | `t-button`，路径`tdesign-miniprogram/button/button`；`theme="primary"`、`variant="outline"/"text"`，主按钮`size="large"` | `--td-button-primary-bg-color`、`--td-button-primary-border-color`映射朱红，`--td-button-primary-color`暖白，`--td-button-border-radius:6px`；使用`disabled/loading`与文字反馈。库不适用时退回原生`button`同尺寸，不换第二库 |
| 创作状态与图像视角 | `t-tag`，路径`tdesign-miniprogram/tag/tag`；`variant="light"`，完整文字说明 | `--td-tag-primary-color`朱红、`--td-tag-primary-light-color`浅强调；不依赖颜色区分。降级为`text`加背景/内边距；阶段标题与视角标签必须分开 |
| 线稿/设色/完成效果分组 | `view`章节 + `text`标题 + 记录列表 | 简单纵向卡片，不做依赖动画的时间线；无可靠日期就不显示日期，也不暗示精确时间间隔 |
| 加载 | `t-loading`，路径`tdesign-miniprogram/loading/loading`，`theme="spinner" text="正在载入作品"` | 以`--td-loading-color`和`--td-loading-text-color`定色；同屏一个明确加载反馈，不阻断返回。兼容受限时纯文字`indicator="{{false}}"`，不以无限旋转掩盖失败 |
| 空、错误、未找到 | `t-empty`，路径`tdesign-miniprogram/empty/empty`；`description`与`action`插槽中的`t-button` | `--td-empty-description-color`映射次文字。无需远程插图；降级为`view/text/button`，保留原因、重试或返回目录 |
| 微信朋友分享 | 原生`button open-type="share"` + 页面`onShareAppMessage`返回作品标题和含稳定ID的路径 | 原生按钮以相同令牌呈现；不把HTML分享说明弹层搬成假微信面板。失败/取消不提示分享成功；无API环境只展示不可用说明 |
| 短反馈/字段错误 | 页面内`view/text`；操作按钮相邻反馈 | 关键错误持续可见，不只使用一闪而过的Toast；库样式不可用时保留纯文字及按钮 |
| 电脑编辑控件 | 本轮原生HTML `input/select/textarea/button`、`fieldset/legend` | 共享令牌与字段层级，不硬套WXML、也不据此批准TDesign React。未来若确需小程序表单，原生`input/textarea/picker/checkbox-group/radio-group`可映射，但本轮不增加手机管理页 |

原生预览默认菜单含保存和发送图片。为不主动增加图片下载入口，建议正式实现设置`showmenu:false`（官方标注基础库2.13.0起），页面图片不启用`show-menu-by-longpress`。最低基础库尚未选；不把此建议视为已批准版本，不承诺阻止截图或系统行为。若兼容性不满足，需复核平台交互，不能静默改成自研复杂图片浏览器。

## 5. 手机连通页面

| 页面 | 信息与主操作 | 去向 |
| --- | --- | --- |
| 精选 | 作品馆名称、简短定位、大图精选、系列入口、全部作品入口；精选与顺序由维护者配置 | 卡片进入作品；系列进入系列详情；全部作品切换「作品」tab |
| 作品目录 | 封面、名称、创作状态；不加入未经确认的搜索/筛选体系 | 点击进入作品；保留当前tab的选中反馈 |
| 系列详情 | 系列名称、说明、所属作品；归属是引用，不复制作品数据 | 打开与其它系列相同ID的作品；返回来路 |
| 作品详情 | 维护者指定的整体图在先；名称、短说明、创作状态；有值才显示年份/材料/尺寸；随后按阶段展示创作记录 | 点击图片放大；分享作品入口；返回来路 |
| 图片欣赏 | 当前整幅或局部图、明确关闭/返回；尽量放大但不变形裁切 | 关闭回详情，不跳到其它作品 |
| 分享入口说明（仅原型） | 明确「本地模拟」，解释转发作品而非下载图片 | 可看接收者冷启动等价入口；没有网络、剪贴板或微信发送行为 |

详情记录分别显示阶段（线稿/设色/完成效果）与视角（整体/局部）。创作状态只表示创作进度，不能推导公开/隐藏；创作中作品可供欣赏。同一作品被多个系列引用时，名称、说明、图像、记录及状态必须一致。

## 6. 电脑核心编辑页与字段映射

一页完成选择已有作品或新建 → 编辑资料 → 选图与记录 → 关联系列 → 精选排序 → 来源核对 → 本地保存/手机预览。系列新建、改名、改说明在独立小节完成，不混入作品名称字段。两位维护者权限相同；本轮没有登录表单或真实权限判定。

以下是**UI语义到逻辑数据的映射**，不是已批准数据库、请求字段或现有脚本API承诺；正式接口命名可调整，关系不得改变。

| 逻辑字段 | 编辑控件 | 手机使用 / 约束 |
| --- | --- | --- |
| 作品稳定ID | 系统保留，不作为标题输入 | 路由、分享、系列引用共用；改名/改系列不变 |
| 名称、简短说明 | 标签清晰的文本框、文本域；必填 | 卡片标题、详情正文；不得以整理者描述冒充作者原话 |
| 创作状态 | 两值单选或下拉：创作中/已完成；必填 | 文本状态标签，与是否公开无关 |
| 整体展示图引用 | 图片选项单选；必填 | 详情首图；明确标识整体图，不将局部冒作整体 |
| 封面引用 | 图片选项单选，由维护者指定 | 卡片封面；不默认最新上传图，不裁切主体 |
| 创作年份、材料、尺寸 | 可选输入，附字段提示 | 仅有实际值才展示；空值不补「未知年份」等伪信息 |
| 系列ID集合 | 多选项，允许空或多选 | 多对多关联；一个作品只有一份内容 |
| 精选标记、排序数值 | 勾选与数值输入 | 首页精选和列表排序；原型排序只为演示规则，最终排序范围/并列规则需在接口设计中确认 |
| 图片引用/视角/来源 | 本地图像选择、整体/局部选项、来源关联 | 预览与记录引用同一图；正式原图和展示资源的存储形态未定 |
| 创作记录所属作品、阶段 | 当前作品下新增记录；阶段下拉 | 记录只属于当前作品；以阶段组织，不能用局部代替阶段 |
| 记录图像、说明、可靠日期 | 图像引用、说明输入、可空日期 | 记录图/说明/视角；没有可靠创作日期就留空，笔记发布日期不能替代 |
| 系列稳定ID、名称、说明 | 系列编辑小节，新建/改名/改说明 | 系列入口和详情；改名不改变既有引用 |
| 来源笔记ID/引用、归属说明 | 独立来源核对区 | 保留可核对来源与归属；作品/记录待确认原因不能伪装成已归并 |

系列封面、系列/记录显示顺序等既有实现提案细项并未因核心页聚焦而取消；其最终控件安排仍需后续完整后台设计确认，本轮不声称全部后台界面已经交付。

本地选图只产生内存预览对象URL，不上传服务器；读取失败有可见反馈，重选可恢复。重置/离开时释放对象URL；不保存到localStorage或磁盘。保存失败保留当前输入；成功文案必须为「已更新本页演示数据，未发布线上」。同页手机视图读取同一内存作品，不复制每个系列中的作品。

## 7. 状态与字段错误

| 状态 | 手机设计 | 电脑设计与恢复 |
| --- | --- | --- |
| 正常 | 页面数据、图片和可操作入口完整 | 表单可编辑；保存只更新演示内存 |
| 加载 | 内容区加载提示，导航/返回仍可用；不假报完成比例 | 保存处理中显示操作反馈，避免重复提交；原型由场景控制模拟，不声称真实请求 |
| 空 | 「暂无作品/本系列暂无作品」与返回或浏览其它入口 | 新建表单不是错误；可选系列为空时仍可录入作品 |
| 错误 | 明确「暂时无法载入」及重试；图片错误局部展示，不把错误当空结果 | 保存失败保留字段；说明未保存并可重试 |
| 未找到作品 | 「未找到这件作品」及返回作品目录 | 不为缺失ID编造作品；不是撤下/旧分享专项流程 |
| 管理访问拒绝 | 不阻断观众浏览、不弹微信个人授权 | 拒绝显示编辑表单，提示无管理权限并提供返回作品馆；工具栏标注仅模拟管理权限 |
| 字段错误 | 不把不完整作品写入观众目录 | 顶部摘要+字段旁文字；名称/说明为空、状态无效、整体图缺失/引用无效等逐项定位；可选日期填入后需合法，不能强制补日期 |

保存校验失败不得清空已填字段或只改变边框颜色；焦点可定位首个错误，帮助文字说明如何修正。真实后台最终仍需服务端校验维护者身份与数据，本地权限开关不构成任何安全边界。原型场景控件位于画布外：normal/loading/empty/error、管理allowed/denied、大字体和重置；不能变成正式产品入口。

## 8. 素材、文字与归并真实性

- 本轮使用本地`source-01-xiwangmu.jpg`、`source-03-dunhuang.jpg`、`source-15-hand.jpg`作版式演示；它们是现有素材配图，不称为作者交付的原图，也不据此确认正式作品名、版权交付或作者说明。
- 画布外持续标明：描述性名称、创作状态、多记录/跨系列归属均含演示数据，待作者确认。为演示阶段关系而组合的记录不能被理解为已证实属于同一幅作品。
- 43篇笔记是来源索引，不等于43件作品；最终需逐条记录确认归属或待确认原因。本原型不冒充已完成43条核对。
- 日期仅在可靠时出现；不将发布日期填作创作日期。年份、材料、尺寸为空则不展示，不能补造艺术史背景、技法或尺寸。
- 图片保留完整比例；说明使用中性、明确的演示措辞。公开页面不额外增加来源社交导流入口；维护来源供核对使用。

## 9. 生命周期与分享冷启动提案

本节是待设计确认的体验提案，**不是永久后台工作流或缓存协议决策**。

| 场景 | 体验建议 | 本地原型边界 |
| --- | --- | --- |
| 新进入 | 无作品入口时进入精选；内容加载/失败有反馈 | 从默认演示目录生成当前会话数据 |
| 返回与重新选择 | 普通返回沿页面来路；切换作品后清除前一作品的欣赏层，不展示错图 | 局部路由历史模拟；最终滚动位置保留策略未承诺 |
| 关闭后重开 | 普通入口回精选；作品分享入口优先定位该作品，不依赖上次页面内存 | 刷新后还原默认数据，之前本地编辑/选图不跨会话保留 |
| 多页面一致性 | 页面按稳定作品ID读取共同内容来源，系列仅保存关系 | 当前页内共享内存模型，不是服务端同步 |
| 朋友分享冷启动 | `onShareAppMessage`给出含稳定ID的完整页面路径；接收端`onLoad(query)`取ID后独立读取公开作品；无效/失败有返回目录或重试 | URL fragment只定位默认演示作品，可模拟从入口打开；新建的内存作品不因此成为跨设备内容 |

观众免登录只读是现有体验提案，尚未成为批准的身份方案；不采集观众头像、昵称、手机号。不将客户端内存、对象URL、HTML路由参数视为线上数据源。最终共享内容服务、持久化、图片存储、合法域名及鉴权待技术确认；分享必须在线解析对应作品才能满足真实跨手机体验。

## 10. 可访问性、窄屏与大字体

- 320px窄屏及大字体目标：不横向溢出；文字换行，双列卡片可降单列，表单列折叠；按钮随文字增高而非截字；图片始终保比例。375px只是基准，不作为硬编码运行宽度。
- 正文和必要说明目标对比度至少4.5:1，大字至少3:1；未执行对比度工具检查。状态、错误、选中项均同时有文字/结构，不只靠朱红与灰色区分。
- 长名称、长说明、长来源引用可换行；目录即使简化摘要，详情仍能读全；不以极小字体塞满卡片。
- 所有实际按钮、图片欣赏入口、关闭及返回操作具备至少44px热区和清楚名称；装饰PNG不制造重复读屏信息，图片提供作品/视角语义。
- HTML原型使用真实按钮和带label的表单，fieldset/legend组织选择，键盘焦点可见；模态支持关闭、Escape、焦点约束与返回触发点；页面反馈使用可访问状态区域。小程序应按原生组件能力补充无障碍名称，并在目标设备核验，HTML ARIA不能直接视为微信支持证明。
- 降低动画依赖，加载动画停止或禁用后文字仍明确；没有手势独占功能。系统预览的返回与屏幕阅读器表现以真机核验为准。
