# 小程序项目规划

## 产品

- 产品名称：召麐个人作品馆
- 目标用户：普通观众，兼顾绘画爱好者。
- 要解决的问题：集中欣赏作者作品，查看同一作品的整体、局部和创作过程。
- 用户最重要的一次操作：找到作品，欣赏整体与细节，阅读作者说明并转发作品入口。
- 核心业务规则：作品为独立展示单元；创作记录归属于作品；系列与作品为多对多关系；创作阶段与图像视角分开记录；创作中作品可公开；归并与正式名称以作者确认为准。
- 使用者和协作方式：观众浏览；用户与作者通过电脑网页后台共同维护，权限相同，均可直接发布。
- 数据保留和共享要求：本地SQLite与独立图片目录已实现；两端读取同一份内容。公网部署、域名与费用另行确认。
- 外部业务资料来源：根目录 PRODUCT-DECISIONS.md、GLOSSARY.md、IMPLEMENTATION-PROPOSAL.md；素材索引见 [43篇图文整理报告](../../../zhaolin-all-image-notes-20261022.md)，记录43篇图文、44张配图，不等于43件作品。正式内容以作者交付为准。
- 高影响字段确认状态：待确认；作品归并、正式名称、作者说明与原图尚未取得完整确认。
- 需求确认日期：2026-10-22（用户在结构化提问中选择“需求确认”）。

## 首版范围

- 必须实现：以下首版范围已于2026-10-22获得用户明确确认。
  - 小程序：精选与系列入口、全部作品浏览、作品详情、整体与局部图片放大、创作记录与状态、微信转发作品入口。
  - 电脑后台：两位维护者分别登录并具有相同权限，维护作品、原图、说明、阶段记录、系列、封面、精选与排序，核对素材来源。
  - 共享内容能力：后台维护的内容可供小程序读取；管理写入校验维护者权限；部署与存储方式另行确认。
  - 内容整理：覆盖43条素材来源，逐条记录已确认归属或待作者确认原因，不假造作品归并。
- 暂不实现：收藏、图片保存、联系作者、评论、交易、临摹教学、自动抓取与同步；不扩展草稿版本、作者审批、冲突版本管理、撤下恢复及旧分享特殊处理。
- 上线成功标准：后台录入并调整内容后，小程序读取对应作品、图像和排序；同一作品出现在多个系列时内容一致；阶段与视角不混淆；未登录者不能管理写入；两位维护者权限相同；微信分享打开对应作品；43条素材均有去向或明确待确认原因。正式验收需开发者工具与真机证据。
- 首版范围确认日期：2026-10-22（用户在结构化提问中选择“首版范围确认”）。

核心闭环提案：维护者录入作者确认的作品与原图 → 配置系列和精选 → 观众浏览、放大和阅读 → 转发作品 → 接收者进入同一件作品。

风险：正式素材与归并尚未确认；后台需要在线数据与图片存储，但费用与部署方案未批准；微信分享、平台类目与隐私等尚未核验。HTML 只能验证设计，不能替代微信运行证据。
