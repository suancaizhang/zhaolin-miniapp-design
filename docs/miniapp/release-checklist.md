## 本地工程与内容

- [x] 四页面只读包内目录；没有API切换或业务HTTP请求，不依赖admin/server。
- [x] JPG展示图、缩略图、5:4分享封面和内嵌图标字体由构建提供。
- [x] 观众无需登录；当前源码不采集头像昵称、手机号或位置，不使用云环境。
- [x] 微信源码根为`miniapp/`；后台、素材源文件、数据库、文档和工具在源码根之外。
- [x] 默认构建只处理小程序；TDesign锁定1.17.0并复制44个运行依赖文件，保留MIT许可证。
- [x] 图片目录显式纳入公共打包配置；来源信息、下载素材和派生图片校验值有仓库记录。
- [x] 移除未确认创作状态；不将30个图像条目视为30件已确认作品，不将画面观察视为实际时间线。
- [x] 当前源码有图片读取失败、重试、卸载后过期响应保护，以及正常返回/冷入口/返回失败切图集处理。
- [x] 当前返回按钮有`size="mini"`及`.back-row > .back-link`样式；历史浏览器夹具通过不等于微信原生效果通过。
- [ ] 媒体优化预算通过：构建报告的`withinMediaBudget`当前为`false`，200,000字节是项目保守预算。超限只警告，构建退出成功不能证明该项通过。

每次准备上传都重新执行README中的构建命令，查看`dist/miniapp-release-report.json`。`sourceBytes`的2MiB断言是本地源码预算，不是微信实际上传包。精确体积不在多份清单重复维护。

当前继续使用包内图片；若实施静态托管，则必须取得真实HTTPS地址，配置相应微信下载合法域名，替换资源路径并重新验证显示、放大、分享和实际包体。历史`dist/gallery-media.zip`不随当前构建更新，不能直接视为最新版。
