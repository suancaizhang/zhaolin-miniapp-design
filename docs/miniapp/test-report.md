## 诊断与修复记录

- Host冒烟最初用Node fetch覆盖Host，实际服务收到的仍是127.0.0.1；最小HTTP回显对照证明fetch没有发送该覆盖。改用node:http后收到非法Host并返回403，无服务端Host放宽。
- Windows动态端口/重启连接复用使临时客户端出现EADDRINUSE/ETIMEDOUT；临时闭环改用独立固定测试端口并在重启后切换端口。未修改产品监听范围或添加自动网络重试。
- 超限JSON最初ECONNRESET：中央异常处理在请求正文尚未读完时强制Connection:close。改为继续丢弃正文并正常返回错误，原场景通过；声明长度、流式越界及12MiB图片的413永久回归通过。
- WXML页面状态、图片、可选资料的31处条件缺少数据绑定；已修正，定向静态检查为0。原产物脚本和TypeScript不能检出该语义问题，不把它们视为视觉验收。
- 作品/系列未编辑表单刷新后仍显示旧值：真实React组件先失败，修复后同步干净表单并保留已修改输入，四组转换通过。
