查看来源、组件映射与未验证项

参考核验日期：2026-10-22。未安装组件依赖；版本为所读取官方仓库的快照，不表示生产环境已锁定版本。三套为候选方向，不混用组件库；选定后只采用一个主组件体系。

  • 微信官方小程序设计指南：重点突出、导航明确、胶囊避让、2—5项标签导航、系统字体、触控与375px基准。
  • WeUI WXSS：官方仓库 package.json 快照为2.6.26；许可证声明主体为 MIT、第三方依赖需各自遵循许可。本页面只参考布局，不复制库源码。
  • TDesign MiniProgram：官方仓库组件包快照为1.17.0；MIT 许可证。B 为其组件模式的 HTML 示意，未声称已运行小程序组件。
  • 素材依据：43篇图文整理报告、封面索引01—15。图片仅用于本地设计比较，正式内容待作者提供与确认。
  • 底部导航图标：本次绘制的项目本地72×72 PNG，精选/作品均提供普通态与选中态；无需外部图标字体或远程资源。
